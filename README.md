## 🎮 Играть

Просто откройте файл `index.html` в вашем браузере - игра полностью работает локально!

## ✨ Особенности

### 🎯 Основные механики
- **Кликайте по банджо** для получения банджо
- **Покупайте улучшения** для увеличения силы клика
- **Стройте структуры** для автоматического заработка
- **Получайте ачивки** за различные достижения
- **Автосохранение** прогресса каждые 10 секунд
- **Оффлайн-доход** - получайте банджо даже когда игра закрыта!

### 📊 Системы игры
- **52 уникальные структуры** в 13 категориях
- **8 уровней улучшений** для кликов
- **12 ачивок** для коллекционирования
- **Масштабирование до 10^40 банджо/секунду!**
- **Форматирование больших чисел** (K, M, B, T, Q, S, O, N)

## 🎮 Геймплей

### Начало игры
1. Кликайте на банджо в центре экрана
2. Накапливайте первые банджо
3. Покупайте первые улучшения и структуры

### Стратегия развития
- **Ранняя игра**: фокус на улучшениях клика
- **Средняя игра**: баланс между структурами и улучшениями  
- **Поздняя игра**: массовая покупка высокоуровневых структур

## 🛠️ Разработка

### Технологии
- **Чистый HTML5, CSS3, JavaScript**
- **Local Storage** для сохранения прогресса
- **CSS Grid** и **Flexbox** для адаптивного дизайна
- **SVG** для изображения банджо

### Особенности реализации
- **Полностью клиентская** - не требует сервера
- **Адаптивный дизайн** - работает на ПК и мобильных
- **Оптимизированная производительность** - плавная анимация даже при больших числах
- **Чистый код** - легко модифицировать и расширять
